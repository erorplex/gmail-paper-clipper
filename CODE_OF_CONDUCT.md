# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, keep discussions about the work, and do not harass anyone.

Report unacceptable behaviour privately to the maintainer through
[GitHub's private reporting](https://github.com/erorplex/gmail-paper-clipper/security/advisories/new) or by
contacting [@erorplex](https://github.com/erorplex). Reports are handled confidentially.
